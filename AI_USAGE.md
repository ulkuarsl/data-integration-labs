## Lab 3 – Version Control Software

**Date:** 10–12 November 2026

**Tool and Model:** ChatGPT (OpenAI, GPT-6)

### Prompts (summarized)

- How can I use Git commands to manage my local repository?
- What is the difference between `git add`, `git commit` and `git push`?
- How can I stage individual changes using `git add -p`?
- How can I restore deleted files and undo Git operations?
- What is the difference between `git commit --amend` and `git revert`?
- How can I create branches and perform a merge?
- What causes a merge conflict, and how can I resolve it?
- How can I analyze the commit history of a GitHub repository?
- How do I create GitHub Issues and Pull Requests?
- How can I document my results in Markdown?

### How I used AI

I used ChatGPT throughout Lab 3 to understand Git concepts, learn Git Bash commands and complete the practical exercises step by step.

**Task 1 – Visualizing Git**

ChatGPT helped me understand Git branches, commits and merges and how to document the results of the visualization exercises.

**Task 2 – Git Setup**

ChatGPT explained how to clone a repository, configure Git, inspect commit history and push local commits to GitHub.

**Task 3 – Step by Step**

I used ChatGPT to understand interactive staging with `git add -p`, the purpose of `.gitignore` and how to document changes to my data download script.

**Task 4 – Undo**

ChatGPT explained how to restore deleted files, unstage changes, amend commit messages and revert commits that had already been pushed.

**Task 5 – Branches and Merge Conflicts**

ChatGPT guided me through creating branches, performing a fast-forward merge and resolving a merge conflict in `countries.csv`.

It also helped me write the documentation in `conflict.md`.

**Task 6 – Analyzing Git History**

ChatGPT suggested Git commands for investigating the commit history of the `datasets/co2-ppm` repository.

I executed the commands and shared their outputs. ChatGPT helped me interpret the results and prepare `history.md`.

**Task 7 – Team Collaboration**

ChatGPT explained the workflow for creating GitHub Issues, feature branches and Pull Requests.

It also helped me prepare the Markdown documentation for the exercises.

### My own contribution

I executed the Git commands myself, created and edited the files, resolved the merge conflict and checked the results using Git Bash and GitHub.

I provided the actual command outputs so that the explanations and documentation could be based on my results.

### Verification

I checked my work using commands such as:

- `git status`
- `git log`
- `git diff`
- `git show`
- `git branch`

I also checked that my commits were successfully pushed to GitHub.

For the merge conflict exercise, I verified that the final CSV file contained both the updated country names and the numeric country codes.

For the Git history analysis, I used the actual outputs from the cloned `co2-ppm` repository.

### Reflection

ChatGPT helped me understand unfamiliar Git commands and organize the documentation.

The most useful part was learning how to recover from mistakes without losing my work.

I also learned that Git commands can affect files and commit history, so it is important to understand their purpose and verify the results rather than blindly following AI-generated instructions.
