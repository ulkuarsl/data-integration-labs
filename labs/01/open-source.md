# Open Source Project Analysis: pandas

## Project Overview

**Project:** pandas

**Repository:** https://github.com/pandas-dev/pandas

**Description:** pandas is an open-source Python library used for data manipulation and analysis.

## 1. Licence
**Licence:** BSD 3-Clause License

**Type:** Permissive

The pandas project uses the BSD 3-Clause License. It is a permissive open-source licence, which means
that users can use, modify, and distribute the code.

If I copy code from pandas into my own project, I must keep the copyright notice, licence conditions,
and disclaimer.

I also cannot use the names of the copyright holdersor contributors to promote my project without permission.

**Source:** [pandas LICENSE](https://github.com/pandas-dev/pandas/blob/main/LICENSE)

## 4. People  
### How many contributors does it have?
The pandas project currently has 3,887 contributors.  
These contributors help develop the library, fix bugs, improve documentation and add new features.

### Who decides what gets merged?

The pandas project is managed by its Core Team.

Anyone can contribute to the project by submitting
a Pull Request (PR). However, only Core Team members have permission
to merge Pull Requests into the main repository.

Decisions are usually made through consensus.

## 5. Money
### How is pandas funded?
pandas is a free and open-source project.

It is mainly developed by volunteers, but it also receives
financial and organizational support.

The project is supported by NumFOCUS, a non-profit
organization that provides financial, legal and
administrative support.

Companies such as Tidelift and Bodo also support pandas.

Additionally, individuals and organizations can
donate money to support the project.

Therefore, pandas is funded through a combination
of volunteer work, company support and donations.

## 7. Your Way In
### How can I contribute to pandas?
According to the pandas contributing guide,
new contributors can follow these steps:

1. Find an issue on GitHub.
2. Fork the pandas repository.
3. Make changes and test them.
4. Create a Pull Request (PR).
5. Wait for the maintainers to review the changes.
6. Make improvements if requested.
7. If approved, a Core Team member can merge the PR.

### Good First Issues

Pandas uses the label `good first issue` to mark
tasks that may be suitable for new contributors.

These issues can help beginners gain experience
with open-source development.
As a beginner, I could start by improving
documentation or fixing small issues.
